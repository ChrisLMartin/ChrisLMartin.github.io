Testing keyless host storage for Logic Apps Standard

What a sandbox test revealed about runtime identity, restart behaviour and storage permissions.

I wanted to know whether a Logic Apps Standard workflow could start and run with key authentication disabled on its host storage account. I built a small sandbox to separate identity selection, storage access and network configuration.

Prove the runtime, not just the deployment

A successful infrastructure deployment only tells you that Azure accepted the configuration. I used a stateful workflow to check whether the host actually started, ran the workflow and stayed healthy after a restart. I gave each identity variant time for its role assignments to take effect before treating a failed startup as evidence.

In this setup, the system-assigned identity variants failed to start the host. A user-assigned identity, explicitly selected for the host storage connection, started successfully and continued working after restart. The sandbox had network access to the required storage services. This result is specific to the hosting setup I tested.

Reduce the grants and repeat the test

After establishing a working configuration, I removed broader permissions and reran the workflow. The user-assigned identity needed the Blob, Queue and Table Data Contributor roles in that setup. The management-plane Storage Account Contributor role was unnecessary. Testing the smaller role set after restart gave me more confidence than checking a single successful run.

I also verified that a separate Key Vault reference continued to resolve through the app’s system-assigned identity. Host storage and Key Vault reference resolution are separate jobs, so test each through the identity it is supposed to use.

Before adopting it

Repeat the test in the hosting plan and networking model you intend to use. Include your deployment method, workflow execution and a restart. Review network reachability for each storage service and keep a recovery path until the new configuration has proved itself.
